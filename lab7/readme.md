# Лабораторная работа №7 — API, исключения и логирование

Карелина Милана, P3122

Учебный проект на Python: получение курсов валют из JSON API,
декоратор логирования и модульные тесты на `unittest`.

## Что реализовано

- `get_currencies` возвращает поле `Value` для запрошенных кодов валют.
  Это значение за `Nominal` единиц валюты в источнике, без пересчёта на одну единицу.
- Ошибки HTTP/соединения преобразуются в `ConnectionError`; некорректный JSON,
  отсутствующие поля и неверные типы значений обрабатываются отдельно.
- Декоратор `logger` поддерживает поток (`StringIO`, консоль) и `logging.Logger`:
  записывает начало, результат или исключение и передаёт исключение дальше.
- В `lab7.py` также сохранён пример решения квадратного уравнения.

## Установка и запуск тестов

Из корня репозитория, после активации своего виртуального окружения:

```bash
python -m pip install -r lab7/requirements.txt
python -m unittest discover -s lab7 -p "lab7test.py" -v
```

Либо из папки `lab7`:

```bash
python -m unittest lab7test -v
```

## Что проверяют тесты

- Выбор нужных валют, пустой список, целые и дробные значения.
- Независимые проверки неизвестных валют и неверных типов значений.
- Отсутствующие поля `Valute` / `Value`, некорректный JSON.
- HTTP 404/500, сбой соединения, тайм-аут и некорректный URL.
- Передачу пользовательского URL в HTTP-клиент.
- Логи успешного вызова и ошибки для обоих типов обработчиков.
- Повторное выбрасывание того же исключения, передачу аргументов,
  результата `None` и сохранение метаданных функции.

HTTP-вызов `requests.get` заменён через `unittest.mock.patch`.
Вместо живого API используется фиксированный учебный JSON и настоящий
`requests.Response`: парсинг и проверка HTTP-статуса выполняются реально.
Тесты не требуют сети и не зависят от текущего курса. Каждый ошибочный
случай имеет собственный `assertRaises`; повторяющиеся случаи оформлены через `subTest`.

Это модульные тесты, а не проверка доступности внешнего сервиса.
Они не заявляют полное покрытие всей лабы: например, `solve_quadratic`
в этом наборе отдельно не проверяется.

## Запуск демонстрации

```bash
python lab7/lab7.py
```

Демонстрации нужен интернет. Исходная функция выполняет HTTP-запрос без
явного тайм-аута; обработка исключения `Timeout` проверяется тестом,
но сам тайм-аут в клиенте не настроен.
При импорте и запуске исходного модуля создаются лог-файлы `currency.log`
и `quadratic.log` в текущей папке. Они не нужны для публикации исходников.
